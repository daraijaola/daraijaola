I build autonomous agents and the payment rails they run on, mostly at hackathons, mostly shipped to mainnet before the deadline. Home is the **TON** community; the work spans Starknet, Solana, Sui and Stellar. Everything I ship goes out under **16labs**, the studio I'm building into a company.

### Selected work

| | | |
|---|---|---|
| **[agentr](https://github.com/daraijaola/agentr)** | AI agent factory for TON and Telegram: agents that hold wallets, call real tools and live inside chat. | TypeScript · TON · Telegram |
| **[Runbox](https://github.com/daraijaola/Runbox)** | Pay-per-use isolated code execution for agents. Two npm packages (`runbox-client`, `runbox-mcp`), metered with x402 and the Machine Payment Protocol on Stellar. | TypeScript · Stellar · MCP |
| **[veritas](https://github.com/daraijaola/veritas)** | Tamper-proof trading track records: every call sealed as a Walrus blob and committed on Sui mainnet, so a win rate can't be edited after the fact. | TypeScript · Move · Sui |
| **[kethic-compiler](https://github.com/daraijaola/kethic-compiler)** | An AI-native compression language: compact intent in, production HTML/CSS/JS and backend out, with accessibility and typed structure enforced by the compiler. | TypeScript |

More in the [repositories](https://github.com/daraijaola?tab=repositories): a Solana reaction-battle game on ephemeral rollups, a cross-chain invoice bot on STON.fi, an autonomous "resident" for Nexus City, portable agent memory, and a proxy that runs Claude Code against any OpenAI-compatible endpoint.
